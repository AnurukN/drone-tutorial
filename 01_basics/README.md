# บทที่ 1: พื้นฐาน Drone

## 🚁 Drone คืออะไร?

Drone (หรือ UAV - Unmanned Aerial Vehicle) คือยานพาหนะทางอากาศที่ไม่มีนักบิน บังคับได้จากระยะไกลหรือบินอัตโนมัติ

---

## 📐 ประเภทของ Drone

### 1. Fixed-Wing (ปีกตรึง)
```
    ___
   /   \
  /     \
─/───────\─
  \     /
   \___/
```
- บินได้นาน, ระยะไกล
- ต้องการพื้นที่ขึ้น-ลง
- ตัวอย่าง: เครื่องบินเล็กบังคับ

### 2. Multi-Rotor (หลายใบพัด)  ← ที่นิยมที่สุด
```
  M1    M2
   \  /
    \/
    /\
   /  \
  M3    M4
```
- **Quadcopter** (4 ใบพัด) - พบบ่อยที่สุด
- **Hexacopter** (6 ใบพัด) - แรง, เสถียรกว่า
- **Octocopter** (8 ใบพัด) - ใช้งานหนัก, ถ่ายภาพ

### 3. Hybrid (ผสม)
- บินขึ้นแนวตั้ง (VTOL) แล้วเปลี่ยนเป็นปีกตรึง
- ได้ประโยชน์ทั้งสองแบบ

---

## ⚙️ หลักการบิน (Quadcopter)

### แรง 4 ทิศทาง
```
ขึ้น/ลง (Throttle)     หมุนซ้าย/ขวา (Yaw)
     ↑                      ↙ ↗
 M1↗   ↖M2              M1↙   ↗M2
   \   /                   \ /
   /   \                   / \
 M3↙   ↘M4              M3↗   ↙M4

เอียงหน้า/หลัง (Pitch)  เอียงซ้าย/ขวา (Roll)
     ↑↑                      ↑↑
 M1↗   M2↗              M1↑↑   M2
   \   /                   \ /
   /   \                   / \
 M3     M4               M3   M4↑↑
```

### การหมุนของมอเตอร์
```
  CW ↻    CCW ↺
M1(↻)   M2(↺)
    ╲   ╱
    ╱   ╲
M3(↺)   M4(↻)
  CCW ↺  CW ↻
```
- มอเตอร์ทแยงหมุนทิศเดียวกัน
- ป้องกัน Torque (แรงบิด) ไม่ให้หมุนตัวเอง

## 🔧 ส่วนประกอบหลัก

```
┌─────────────────────────────────────────┐
│              DRONE SYSTEM               │
│                                         │
│  ┌─────────┐     ┌─────────────────┐   │
│  │ Remote  │────▶│  Receiver (Rx)  │   │
│  │Control  │     └────────┬────────┘   │
│  │ (Tx)   │              │             │
│  └─────────┘     ┌────────▼────────┐   │
│                  │  Flight         │   │
│  ┌─────────┐    │  Controller     │   │
│  │  GPS    │───▶│  (FC)           │   │
│  └─────────┘    │  ArduPilot/PX4  │   │
│                  └──┬──┬──┬──┬────┘   │
│  ┌─────────┐       │  │  │  │         │
│  │ Battery │──────▶│  │  │  │         │
│  │  LiPo   │    ┌──▼──▼──▼──▼───┐    │
│  └─────────┘    │  ESC (×4)     │    │
│                  └──┬──┬──┬──┬───┘    │
│                  ┌──▼──▼──▼──▼───┐    │
│                  │  Motor (×4)   │    │
│                  └───────────────┘    │
└─────────────────────────────────────────┘
```

| ส่วนประกอบ | หน้าที่ |
|-----------|---------|
| Flight Controller (FC) | สมองของโดรน - คำนวณการบิน |
| ESC (Electronic Speed Controller) | ควบคุมความเร็วมอเตอร์ |
| Motor | สร้างแรงขับ |
| Propeller | แปลงความเร็วเป็นแรงยก |
| Battery (LiPo) | แหล่งพลังงาน |
| GPS | ระบุตำแหน่ง |
| IMU (Gyro + Accel) | วัดการเอียง, ความเร็ว |
| Receiver (Rx) | รับสัญญาณจาก Remote |

## 📡 Protocol การสื่อสาร

### 1. MAVLink
- โปรโตคอลมาตรฐานสำหรับ UAV
- ใช้กับ ArduPilot, PX4
- รองรับ Mission Planning, Telemetry

### 2. PWM / PPM / SBUS
- สัญญาณควบคุม RC
- PWM: แต่ละช่องแยกสาย
- SBUS: ทุกช่องรวมสายเดียว (ดีกว่า)

### 3. UART / USB / WiFi / 4G
- เชื่อมต่อ Companion Computer (Raspberry Pi)

---

## 🎮 Flight Modes ที่สำคัญ

| Mode | ความหมาย |
|------|----------|
| **STABILIZE** | ช่วยรักษาระดับ แต่ผู้บังคับต้องควบคุมเอง |
| **ALT_HOLD** | รักษาความสูงอัตโนมัติ |
| **LOITER** | หยุดอยู่กับที่ (GPS) |
| **AUTO** | บินตาม Mission อัตโนมัติ |
| **GUIDED** | รับคำสั่งจาก Software |
| **RTL** | กลับจุดเริ่มต้นอัตโนมัติ |
| **LAND** | ลงจอดอัตโนมัติ |
